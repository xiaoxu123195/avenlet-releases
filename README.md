**Windows 上的 AI Agent，带着一整套顺手的工具**

Agent 在你的电脑上读文件、改文件、跑命令，高危的先问你；能解析 SQLite、MMKV、Plist、Protobuf，能操作连着的手机，能查知识库、记待办。<br>
工具箱里还有数据提取、真机数据浏览器与投屏、HTTP 调试、包名搜索、翻译；按 Alt+Space 随时呼出快捷面板。用 AI 时直接连你自己配置的服务商。免费使用。

## 下载与安装

1. 打开 [最新版](https://github.com/xiaoxu123195/avenlet-releases/releases/latest)，在 Assets 里下载 `Avenlet_<版本>_x64-setup.exe`。
2. 运行安装包。安装到当前用户目录，不需要管理员权限。
3. 安装包暂未做数字签名，Windows 可能提示「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。

**系统要求**：Windows 10 / 11，64 位。需要 Microsoft Edge WebView2 运行时：Windows 11 自带，缺少时安装程序会联网安装。

**核对安装包**（可选）：在 PowerShell 里运行下面的命令，得到的值应和发布页上写的 SHA-256 一致。

```powershell
Get-FileHash "$env:USERPROFILE\Downloads\Avenlet_<版本>_x64-setup.exe"
```

`latest.json` 和 `.sig` 是程序自动更新用的，不用下载。

## 升级与卸载

- **自动更新**：Avenlet 启动后会检查一次新版本，可以在「设置 › 关于」里关掉自动检查，也可以在那里手动检查。
  - 有新版本时，看过更新说明再下载。
  - 点「安装并重启」后，Avenlet 会先保存草稿再安装，装好自动重新打开，设置和草稿都会保留。
  - 下载的安装包要核对数字签名，对不上就不会安装。
- **手动升级**：也可以直接运行新版本的安装包。设置、草稿、收藏和保存的密码都会保留；如果出现卸载旧版本的窗口，不要勾选删除应用数据。不能用旧版本覆盖新版本。
- **从 0.4 升级到 0.5.0**：AI 助手并进了 Agent，以前的对话在第一次打开 0.5.0 时删掉，要留的先在旧版里导出。
- **备份**：在「设置 › 数据与隐私 › 数据」里能备份全部数据、从备份恢复；密码和密钥不在备份里。
- **安装或卸载前**：先从托盘菜单选「退出」，等 Avenlet 保存好草稿。
- **卸载**：在 Windows「设置 → 应用」里卸载。只有勾选了删除应用数据，才会清掉设置和草稿；记住的密码、AI 密钥等存在 Windows 凭据管理器里，卸载不会删除。

## 数据与隐私

Avenlet 不收集、不上传任何数据，也没有使用统计或崩溃报告。只有四种情况会联网：

- 在 HTTP 调试里发请求；
- 用包名搜索查询应用市场；
- 用 AI 功能（包括 Agent、快捷面板里的翻译、知识库的向量化和重排序）时，连你在「设置 › AI」里配置的服务商和你添加的网络 MCP 服务器；在 Agent 里打开联网时，由服务商替你上网搜索；
- 从发布页检查和下载更新（可以在「设置 › 关于」里关掉自动检查）。

前三种情况下，数据直接发往你指定的地址、相应的应用市场或服务商，不经过 Avenlet。Agent 跑的命令和它打开的程序（比如下载依赖、推送代码）会自己联网，和你自己运行一样；推送代码、跑下载的脚本这类会先问你。用 AI 时发出去的是你说的话和附加的文件，Agent 读到的文件内容和命令的输出，以及工具读出来的内容（手机、数据库、待办、知识库、你配的 MCP 服务器）；手机数据、他人信息这类敏感内容，建议用在本机运行的模型。

Agent 读、找、改工作文件夹里的文件，跑一般的命令，不问你；删整个文件夹、推送代码、改系统设置、装软件这类高危的先问，碰 SSH 私钥、浏览器存的密码这类的直接拦下，但规则认不出所有危险的操作。它用你的 Windows 账户跑，没有沙箱；它用 `edit`、`write` 改的文件能撤销，命令改的撤销不了，重要的先备份。

知识库只读你选的文件夹，不改你的文件；入库时文件的文字发给你选的向量模型。标成敏感的库，Agent 里只能用本机和内网的模型查，也不开放给 Claude Code、Codex 这些程序。

打开「对外 MCP」（默认关）后，本机的 Claude Code、Codex 这些程序能用 Avenlet 的工具，包括看手机屏幕、操作手机、往手机写文件和跑命令；它们拿到的内容按它们自己的设置发给它们连的模型。

快捷面板只在你复制后几秒内呼出时读一次剪贴板；剪贴板历史默认关，打开后加密存在本机。文字识别在本机完成，网页搜索是交给默认浏览器打开。
