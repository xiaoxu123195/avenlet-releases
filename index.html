Agent

说一句，它在你的文件夹里做完

读文件、搜代码、跑 PowerShell、改文件，每一步都摆在你眼前；它改的文件，一键就能撤回。

8 个内置工具 往下滚时搭这个页面的光标，就是它们。另外还能用 Avenlet 自己的工具（手机、知识库、待办、解析 SQLite 这类文件），也能接你配的 MCP 服务器。
read读文件，UTF-8、UTF-16、GBK 都认
ls看文件夹里有什么
glob按文件名找，各层文件夹一起找
grep按内容搜，GBK 的文件也搜得到
edit照原文改几处，对不上就一处都不改
write新建或整个重写，照原来的编码和换行
powershell跑命令，跑久了转到后台
job等后台命令打出某一行，或者停下它

危险的先问你

删整个文件夹、动工作文件夹外面的东西、下载运行没见过的包，先停下来问你；读凭据这类直接拦下。平常的读、写、搜不打扰。

它改的文件，能撤回

用你自己的模型

填上你自己的密钥就能用，密钥存在 Windows 凭据管理器里；敏感的资料，交给本机运行的模型。

手机直接连

Android 用内置的 ADB，越狱的 iPhone 走 USB 上的 SSH，不用另装命令行工具；连上就能浏览、提取、投屏。

隐私

只在这几种时候联网

Avenlet 自己联网的就这几种。前三种的数据直接发往你指定的地址、应用市场或服务商，不经过 Avenlet。

不收集、不上传任何数据。没有使用统计，没有崩溃报告，这个网站也没有统计脚本。
5种情况会联网
0个账号要注册
在 HTTP 调试里，你自己发的请求
用包名搜索查应用市场
用 AI 时，连你在「设置 › AI」里配的服务商和网络 MCP 服务器；在 Agent 里打开联网时，由服务商替你上网搜
检查和下载更新，自动检查可以在「设置 › 关于」里关掉
安装时电脑缺少 WebView2，安装程序联网装上

快捷面板里的网页搜索、打开网址，交给你的默认浏览器去打开。Agent 跑的命令和它打开的程序（比如下载依赖、推送代码）会自己联网，和你自己运行一样；推送代码、跑下载的脚本这类会先问你。
